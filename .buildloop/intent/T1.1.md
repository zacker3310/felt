# Intent T1.1: felt, a billiards game

**Originator:** Zac, 2026-10-24, in his words:

> Go build me a billiards game with the physics you've got from the puttX project.
> 8 ball and 9 ball to start.

Follow-up the same day: "pick it up and build it and create repo and commit and push to main".

## What is wanted

- A playable pool game, 8-ball and 9-ball, to start.
- Physics carried over from `~/dev/puttX`: hand-rolled, fixed-step, deterministic, DOM-free
  sim region that Node tests load directly.
- A GitHub repo named `felt`, work committed and pushed to `main`.

## Read into the ask (not stated, chosen as defaults)

- Same delivery shape as puttX: one offline `index.html`, no runtime dependencies, Node and
  Playwright suites as the contract.
- Audience is grown-ups, not puttX's 3-5 year old, so words on screen are fine.
- Opponents: a second player on the same device, or a CPU, so it is playable alone.

## Open

- Hosting (GitHub Pages like puttX) was not asked for. Not done; the repo is private.
- More games (straight pool, snooker), online play, side english: later.
