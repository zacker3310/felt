# Intent T2.1: overhaul

**Originator:** Zac, 2026-10-25, in his words:

> The game is pretty bad. Overhaul. At all costs. Spin up 50 agents if you have to

## What is wanted

A game that feels like pool, not a physics demo. Everything is in scope: physics, controls,
visuals, sound, the CPU, the phone layout.

## Read into the ask (from playing v1)

- **Physics feels wrong.** Spin is a hack (a scalar converted toward roll), there is no side
  english, no throw, no squirt. Pockets are gaps in a line: any centre past the nose drops, so
  pockets are huge and never rattle. Cushion ends are bare segment tips with no jaws.
- **Controls fight you.** The power bar sits half full in signal red when idle. The spin
  widget is one-dimensional. No fine aim on touch.
- **Phone is broken.** The table is a postage stamp beside a 64 px column of power bar.
- **Looks flat.** Pockets are black circles, cushions a 1 px line, no pocketed-ball tray, no
  shot feedback.
- **CPU is one setting.** Shallow search, no difficulty, no position play.
- **Sound is thin.**

## Kept

One offline `index.html`, no libraries, deterministic DOM-free sim region, live roll equals
`simulateShot` byte for byte, tests as the contract.
