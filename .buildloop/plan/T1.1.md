## Verification

## Risks

- Pocket geometry: balls rattling between cushion ends forever. Covered by the fuzz timeout check.
- CPU cost in the browser: each candidate is a full simulation. Bounded candidate count; the
  search yields to the event loop between simulations.
- Live loop drifting from the pure sim: the live loop calls the same `stepTable`, checked in
  `play-check`.
