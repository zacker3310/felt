# Spec: T2.2 bigger balls, perfect pockets, aim feel

**id:** T2.2   **intent:** .buildloop/intent/T2.2.md   **status:** accepted
Extends `.buildloop/spec/T2.1.md`; its ownership table and contract still hold, with these additions.

## Contract additions

- **Table size (sim, stream P).** `setTable(size)`, size `'7' | '9'`, default `'7'` at load.
  It reassigns the table globals: `TL`, `TW`, `HEAD_X`, `FOOT`, `CUSH`, `CUSHION_POLYS`,
  `POCKETS`, `POCKET_R`, `POCKET_AIM` (these become `let`). `TABLE` holds the current size.
  7 ft: playing surface 1.981 x 0.991 m (78 x 39 in). Ball size and pocket mouths/jaws are the
  same on both sizes. Readers must read the globals at call time and never cache them across a
  `setTable` call. The CPU's load-time calibration reruns (or is table independent).
  `newGame(kind)` uses the current table. `setTable` never runs mid-game.
- **Rail width (layout, stream U).** `RAIL` becomes a `let` that `layout()` sets before it fits
  the table and calls `drawTableImage()`: 0.115 m when the shorter viewport side is at least
  700 px, down to about 0.07 m on phones. V's table art must look right at any RAIL in that range.
- **Settings.** `settings.table` (`'7' | '9'`, default `'7'`), in the menu, persisted. U calls
  `setTable(settings.table)` before `newGame`, then `layout()`.
- **Aim (stream U).** Drag on the table swings the cue directly: the aim follows the finger's
  angle about the cue ball 1:1 (pull-to-shoot unchanged). A fine-aim control (a wheel/strip
  beside the power bar, plus keyboard Alt+arrows) turns the aim slowly: about 0.02 deg per px.
  Desktop hover aiming stays absolute.
- **Loupe (stream V).** While the fine-aim control is being dragged (U sets `fineAim = true`), V
  draws a circular magnifier (about 3x) of the ghost-ball contact, placed so the finger and the
  contact are not under it.
- **Pocket style (sim, stream P; added later).** `setPockets(style)`, style `'regulation' | 'generous'`,
  default `'regulation'`, held in `POCKETS_STYLE`. It rebuilds the same globals as `setTable`
  (one `buildTable()` reads both, so either call order gives the same geometry), plus the mouth
  widths `CORNER_W`/`SIDE_W` the CPU reads. Generous: mouths 5.25 in corner, 5.75 in side,
  facings 139 / 100 deg, holes 0.062 / 0.068 m, corner shelf 0.030 m. `settings.pockets` in the
  menu's Table section, persisted; `start()` calls `setPockets` with `setTable`. Never mid-game.

AC4. Fine-aim control: 100 px drag turns the aim 1.5-2.5 deg | play-check

AC6. All suites, lint 0, no em dashes.
