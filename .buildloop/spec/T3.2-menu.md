# Spec: T3.2 the menu

**id:** T3.2   **status:** accepted
Page code only (sections 4 to 7, markup and CSS); the sim region is unchanged. Intent: `.buildloop/intent/T3.2.md`.

## Flow

- **Home** (`#menu` with no game in progress; `data-paused` unset): brand; Play again
  (`#againBtn`, hidden until `settings.last` is set; the setup in words, `setupWords(kind)`, e.g.
  "8-ball vs Hustler (CPU hard), 7 ft"); game tiles `#play8`, `#play9`, `#playB`, each with a
  canvas of its rack on the chosen cloth; solo row `#pracBtn`, `#trickBtn` (stars), `#dailyBtn`
  (day of the month, streak); `#statsBtn`, `#prefsBtn`, `#helpBtn`. Portrait: a column with
  section labels; landscape: brand and buttons share the top row, tiles lie flat. Fits without
  scrolling at 440x956 and 956x440 with the iOS insets.
- **Setup** (`#setupSheet`, `showSetup(kind)`): opponent `#vs2p`/`#vsCpu`; against the CPU three
  cards `#lvEasy` Rookie, `#lvMedium` Regular, `#lvHard` Hustler (with the record against each);
  two players: `#name1`, `#name2` (`settings.names`, trimmed, 12 characters). Pool: `#tb7`/`#tb9`,
  `#pkReg`/`#pkGen`; bumper: `#btOct`/`#btRect`. The rack behind the sheet is the game being set
  up (`previewGame`). `#breakBtn` -> `playSetup(kind)`: `settings.last = kind`, `start(kind)`.
- **Settings** (`#prefsSheet`): `#clGreen`/`#clRed` with a live swatch, `#gFull`/`#gShort`/`#gOff`,
  `#aaOn`/`#aaOff`, `#sndOn`/`#sndOff`, and the diagnostics line.
- **Stats** (`#statsSheet`, `showStats()`): run of wins vs CPU (now, best), trick stars, daily
  streak; a row per game: played, W-L against each opponent, two-player games.
- **How to play** (`#helpSheet`): tabs Controls (touch or mouse words), 8-ball, 9-ball, Bumper,
  Solo. From a paused game it opens on that game's tab.
- **Pause** (`#menu[data-paused]`): the game cards (or the solo session), a kicker naming the
  game and opponent, `#resumeBtn`, then `#restartBtn`, `#exitBtn` (Quit to home, `quitToHome()`),
  `#pPrefsBtn`, `#pHelpBtn`. No home tiles.
- Every sheet has a back button; Esc closes the top sheet first (`escSheet()`), then resumes or
  pauses as before. Sheets rise in over 0.2 s (none with reduced motion).

## Art

`paintArt()` / `paintRack(canvas, kind)`: for a moment the geometry and view are the tile's
game (`setTable`, `setPockets` as booted, so test wrappers see only game calls), the table is
painted by `drawTableImage(w, h)` and the balls by `drawBall`/`drawShadow` into the tile's
context (`artCtx`), then everything is put back. Only with no game in progress. Keyed per
canvas (kind, size, dpr, cloth, table options), repainted on relayout and setting changes.

## Daily shot

`dailyTrick(day)`: `TRICKS[(dayNum(day) * 5) mod 14]`, `dayNum` the UTC day number of the local
date string, so every player gets the same shot on the same date and fourteen days cover all
fourteen. The date is `felt.today` (tests) or the local clock, in page code only. `startDaily()`
runs the trick machinery with `solo.daily = { day, scored }`. The first attempt of a day is
scored (`scoreDaily`): a day after `last` adds one to the streak, a gap resets it to 1; retries,
Show me and later visits that day are practice. `felt.daily.v1`: `{ last, streak, best, made }`;
a streak whose last day is before yesterday reads as 0 (`dailyStreak`).

## Record

`recordGame()` in `finish()` (8-ball, 9-ball, bumper; not solo): `played`, `two` (two players)
or `cpu[level].w|l`, and the run of wins against the CPU (`streak`, `best`; a loss resets it).
`felt.record.v1`, `{ v: 1, kinds, streak, best }`; bad JSON or bad values read as zero.

## Names

Two players: `nameOf(p)` is the given name or Player 1/2; the chip shows its first three
characters (`shortName`) or P1/P2. Against the CPU the pause card says "Rookie (CPU)" etc.; the
in-game words stay "CPU".

## Tests

boot-check (home fits, sheets' targets and contrast, setup options per game, pause menu),
play-check (setup flow, Play again, record on a forced win and a loss, names, settings in their
sheets), solo-check (daily shot by injected date: deterministic, once a day, reset after a gap).
